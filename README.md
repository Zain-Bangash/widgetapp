# Warith App

Warith is a native Android home screen widget app that displays rotating narrations and excerpts from offline Islamic texts.

## 🚀 How to Download and Install (Step-by-Step)

If you just want to use the app on your phone, follow these simple steps:

### Step 1: Find the Latest Build
1. Open this repository on GitHub.
2. Click on the **"Actions"** tab at the top of the page.
3. You will see a list of "workflows". Click on the most recent one (usually at the top) that has a green checkmark ✅.

### Step 2: Download the APK
1. Scroll down to the bottom of that page to the **"Artifacts"** section.
2. Click on the link named **`app-debug`**.
3. This will download a ZIP file to your computer or phone.

### Step 3: Extract and Install
1. Open the downloaded ZIP file and extract the file named `app-debug.apk`.
2. Transfer this `.apk` file to your Android phone (if you downloaded it on a computer).
3. On your phone, tap the `.apk` file to install it.
   - *Note: You might need to allow "Install from Unknown Sources" in your phone's settings.*

### Step 4: Add the Widget
1. Once installed, go to your phone's Home Screen.
2. Long-press on an empty area and select **Widgets**.
3. Look for **"Warith"** in the list.
4. Drag the widget onto your home screen!

---

## 🛠 Features
- **Rotating Narrations**: Randomized excerpts from bundled books.
- **Offline First**: Works entirely without internet.
- **Source Navigation**: Switch between different books directly from the widget.
- **Auto-Rotation**: Optionally advance to a new narration every day at midnight.
- **Minimalist Design**: Clean UI that follows your system's light/dark mode.
